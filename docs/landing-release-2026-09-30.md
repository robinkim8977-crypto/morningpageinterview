# 랜딩 리디자인 출시 — 2026-09-30

운영 주소: https://morningpageinterview.vercel.app

비공개 리디자인의 크림색·올리브색 구성, 이미지, 타이포그래피를 기존 Next.js 서비스에 적용했다. 참조 사이트의 접근 권한은 변경하지 않는다.

## 반영 내용

- 무료 인터뷰/기본 매거진과 선택 구매 AI 미래좌표(2,900원)를 구분하고, 11개 질문·저장 범위·AI 전송·구매 및 생성 순서를 실제 서비스에 맞췄다.
- 첫 답변을 저장한 뒤 실제 인터뷰 Q2로 이어지고, 기존 답변은 이어서 쓰기 또는 명시적 새 인터뷰 선택으로 보호한다.
- 결제 후에는 인터뷰 완료 여부를 확인한다. 작성 중인 인터뷰는 이어 쓰고, 완료 후 분석을 시작한다. 이미 저장된 분석 결과는 계속 열람할 수 있다.
- 예시 리포트, 키보드 탭, 모달, FAQ, 모바일 고정 시작 버튼을 적용했다.
- GA4 이벤트: landing_cta_click, report_sample_open, first_answer_saved, interview_resume. placement와 landing_version=20260930을 전송하며 답변·이름을 담지 않는다. 실제 GA4 수집 결과는 이 배포 검증에 포함하지 않았다.

## 검증

- 자동 테스트 45개 통과. 첫 답변 보존, 저장 실패 시 기존 보고서 보존, 결제 후 완료 여부 검증 포함.
- Next.js production build 통과.
- 320·390·768·1440px 브라우저: 가로 넘침, 이미지 로딩, 시작/예시 모달, FAQ, 키보드 탭, 첫 답변→Q2, 이어 쓰기→Q2, 결제 화면 이동 확인.
- production 빌드 브라우저: 결제 검증 API를 모의 처리하여 미완료 인터뷰의 분석 요청 차단, Q2 이어 쓰기, 완료 인터뷰의 분석 진입 확인. 실제 결제 또는 유료 AI 생성은 실행하지 않았다.
