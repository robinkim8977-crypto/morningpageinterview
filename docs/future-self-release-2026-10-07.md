# 미래의 나 만들기 출시 — 2026-10-07

운영 주소: https://morningpageinterview.vercel.app
복구 기준: 이전 운영 커밋 `8d786d1`.

## 반영 내용

- 승인한 ‘미래의 나 캐릭터 설정 → 하루 상상 → 변화의 이야기 → 현재로 보내기’ 흐름을 실제 서비스에 적용.
- 시작 안내에 정체성과 행동을 연결하는 설명 추가. 자동으로 행동·성과가 보장된다는 표현을, 원하는 삶의 기준과 작은 선택을 찾는 표현으로 정리.
- 유료 미래좌표에 정체성의 이야기, AI가 해석하는 내용, 세 장면·하나의 방향, 30·90·365일 좌표, 72시간 첫 행동을 구체적으로 안내.
- 초반 성격·관심·가치·공간은 선택 또는 직접 입력, 이후 단답에서 서술로 이어지는 11개 질문. 중간 캐릭터 확인과 마지막 기록 확인 제공.
- 선택 한도, 모름 응답, 자동 저장, 저장 실패 시 진행 중단, 답변 복원, 최대 8,000자 처리.
- 질문지 버전 3 도입. 기존 버전 2는 이전 질문·무료 결과·AI 근거 번호를 유지. 이전 유료 분석의 서버 원장 fingerprint 입력도 유지.
- 무료 결과는 선택과 답변만 정리하고, PDF·이미지 저장 지원. AI 분석과 구분.
- AI 해석의 습관 근거를 새 질문 9, 변화 근거를 8~10, 현재로의 연결을 3·9~11로 조정. 빈 답변·모름 응답은 AI 근거에서 제외.
- 결제 완료 인터뷰의 직접 편집을 막아 저장된 유료 결과를 보호. 명시적인 새 인터뷰 시작은 기존 결과 초기화를 안내하며, 이전 완료 인터뷰의 결제 영수증을 새 답변에 재사용하지 않음. 작성 전 구매한 미완료 인터뷰의 영수증은 유지.
- GA4 랜딩 버전 20261007. 답변·별명은 추적 이벤트에 포함하지 않음.

## 검증

- 자동 테스트 51개 통과. 기존 결제·원장·AI 실패·재시도 모의 통합 테스트와 새 질문 번호, 기존 기록, 선택 직접 입력, 모름 응답, 결제 영수증 보존 검증 포함.
- Next.js production build 및 타입 검사 통과.

- 11문항 완료 → 무료 결과, 선택 한도, 직접 입력, 새로고침 복원, 이전 질문 이어 쓰기와 올바른 결과 매핑, 저장 실패 시 이동 중단, 유료 완료 인터뷰 보호 확인. 레이아웃·행동 검사 총 23개 통과.
