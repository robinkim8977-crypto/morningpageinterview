# 카카오페이·네이버페이 연결 절차

현재 코드는 카드, 카카오페이, 네이버페이 채널을 각각 받을 수 있습니다. 간편결제 채널 키가 비어 있으면 구매 화면에 해당 수단을 표시하지 않으므로, 심사 중인 기능이 실수로 공개되지 않습니다. 기존 `NEXT_PUBLIC_PORTONE_CHANNEL_KEY`는 카드 채널의 대체값으로 유지되어 현재 카드 결제도 끊기지 않습니다.

## KCP 답변을 받은 뒤 확인할 내용

KCP가 보내 준 답변에서 아래 두 값을 각각 확인합니다.

- 카카오페이용 KCP 사이트 코드(가맹점 ID)
- 네이버페이용 KCP 사이트 코드(가맹점 ID)

카드용 사이트 코드와 같다고 추측해 입력하지 않습니다. KCP가 별도 코드 또는 별도 심사가 필요하다고 안내하면 그 안내를 우선합니다.

## PortOne 채널 등록 — 카카오페이

1. PortOne 관리자 콘솔에 로그인합니다.
2. 왼쪽 메뉴에서 `결제 연동`을 누릅니다.
3. `연동 관리`를 누릅니다.
4. `채널 관리`를 누릅니다.
5. `채널 추가`를 누릅니다.
6. `실연동`을 선택합니다.
7. PG사에서 `NHN KCP (결제창) V2`를 선택하고 `다음`을 누릅니다.
8. 채널 이름에 `KCP 카카오페이 운영`처럼 구분되는 이름을 입력합니다.
9. KCP가 발급한 **카카오페이용** 사이트 코드와 콘솔이 요구하는 인증 정보를 입력합니다.
10. 과세 유형을 현재 카드 채널과 동일하게 확인한 뒤 `저장`을 누릅니다.
11. 저장된 채널의 `채널 키`를 복사합니다. 사이트 코드가 아니라 `channel-key-...` 형태의 PortOne 채널 키입니다.

## PortOne 채널 등록 — 네이버페이

위 절차를 다시 진행하되 채널 이름을 `KCP 네이버페이 운영`으로 하고, KCP가 발급한 **네이버페이용** 사이트 코드를 입력합니다. 저장 후 네이버페이 채널의 `channel-key-...` 값을 복사합니다.

## Vercel 환경변수 입력

1. Vercel에 로그인합니다.
2. 이 서비스의 프로젝트를 누릅니다.
3. 위쪽 `Settings`를 누릅니다.
4. 왼쪽 `Environment Variables`를 누릅니다.
5. `Add New`를 누릅니다.
6. Type은 채널 키가 브라우저 결제 요청에 쓰이는 공개 식별자이므로 `Config`를 선택합니다.
7. Key에 `NEXT_PUBLIC_PORTONE_CHANNEL_KEY_KAKAOPAY`를 입력합니다.
8. Value에 카카오페이용 PortOne `channel-key-...` 값을 붙여 넣습니다.
9. Environment는 `Production`을 선택하고 `Save`를 누릅니다.
10. 다시 `Add New`를 누르고 같은 방식으로 `NEXT_PUBLIC_PORTONE_CHANNEL_KEY_NAVERPAY`와 네이버페이용 채널 키를 저장합니다.
11. 카드 채널을 새 변수명으로 정리하려면 `NEXT_PUBLIC_PORTONE_CHANNEL_KEY_CARD`에 현재 카드용 채널 키를 추가합니다. 이 작업은 선택사항이며, 기존 `NEXT_PUBLIC_PORTONE_CHANNEL_KEY`만 있어도 카드 결제는 유지됩니다.

`PORTONE_API_SECRET`은 서버 비밀정보이므로 `Secret`이어야 합니다. 위의 `NEXT_PUBLIC_...CHANNEL_KEY...` 값들과 서로 혼동하지 않습니다.

## 재배포와 노출 확인

1. Vercel 프로젝트 위쪽 `Deployments`를 누릅니다.
2. 가장 최근 Production 배포 오른쪽의 점 세 개(`…`)를 누릅니다.
3. `Redeploy`를 누릅니다.
4. 환경변수를 최신 값으로 사용할지 묻는 항목이 보이면 최신 환경변수 사용을 선택합니다.
5. 다시 `Redeploy`를 누릅니다.
6. 상태가 `Ready`가 되면 운영 사이트의 미래좌표 구매 화면을 엽니다.
7. `신용·체크카드`, `카카오페이`, `네이버페이` 세 선택지가 모두 보이는지 확인합니다.

## 홍보 전 실결제 확인

각 결제 수단별로 2,900원을 한 번 결제한 뒤 바로 취소하여 승인과 환불을 모두 확인합니다. 결제번호는 운영 복구 화면에서도 한 번 조회합니다. 모바일에서는 Android Chrome과 iPhone Safari에서 결제 앱 이동 후 사이트로 정상 복귀하는지 각각 확인합니다.

심사 완료 전에는 간편결제 환경변수를 넣지 않습니다. 환경변수를 넣은 뒤에도 결제창에서 잘못된 가맹점명, 테스트 모드, 승인 오류가 보이면 홍보하지 말고 해당 변수만 제거한 뒤 재배포하여 해당 수단을 다시 숨깁니다.
